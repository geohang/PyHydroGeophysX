# Synthetic LM+HM line for LCI testing

This deterministic example is a nine-station TEM line stored in the same
SQLite project layout accepted by the TEMcompany/TEM2Go data reader.

- `project.db`: noisy LM+HM observations, in-use flags, survey geometry, and
  inversion defaults.
- `truth_model.csv`: the known eight-layer resistivity model in a
  human-readable form.
- `truth_model.npy`: the same truth array with shape `(9, 8)`.

The stations are spaced 10 m apart. Resistivity increases smoothly from left
to right, while a fixed depth-dependent multiplier gives vertical structure.
LM has 7 gates, HM has 11 gates, and deterministic Gaussian relative noise is
3% (`seed=20260730`).

## Workbench quick test

In **EM Processing**, select the `TEMcompany / TEM2Go` data format, click
**Load data...**, and choose this folder. Keep `LM+HM`, then run the line
inversion. The embedded settings use eight layers, a 40 ohm-m start model, and
same-line L2 lateral smoothness of 1.3.

The example is also available to AQUAH as `synthetic_tem_lci`.

With the current solver and six iterations, the expected LM+HM LCI result has
approximately 0.046 log10 model RMSE and 0.990 log10 model correlation. Small
changes can occur when numerical dependencies change.
