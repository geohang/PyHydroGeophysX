Ex. 3D ERT Forward Modeling with MODFLOW Integration
====================================================

This example demonstrates complete 3D ERT forward modeling with MODFLOW integration,
mesh creation using Mesh3DCreator, topography handling, and PyVista visualization.

The workflow includes:

1. Loading MODFLOW water content and porosity data
2. Creating 3D mesh with topography and electrode positions
3. Interpolating hydrological properties to 3D mesh
4. Converting water content to resistivity using petrophysical relationships
5. Performing 3D ERT forward modeling
6. Visualizing results with PyVista

Step 3: Create 3D Mesh with Electrodes
--------------------------------------

Use the Mesh3DCreator class to create a 3D mesh with surface electrodes.

.. code-block:: Python

    # Create mesh creator
    mesh_creator = Mesh3DCreator()

    # Define electrode positions on surface
    n_electrodes = 24
    electrode_spacing = 5.0
    electrode_x = np.arange(n_electrodes) * electrode_spacing
    electrode_y = np.zeros(n_electrodes) + 50.0
    electrode_z = np.zeros(n_electrodes)  # Will be set by topography

    # Create 3D mesh with topography
    mesh = mesh_creator.create_3d_mesh_with_topography(
        electrodes=np.column_stack([electrode_x, electrode_y, electrode_z]),
        topography=top,
        depth=50.0,
        quality=33.0
    )
