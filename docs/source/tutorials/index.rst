Tutorials and Workflows
=======================

These short tutorials map directly to common user goals and runnable examples.
Start with one workflow and then open the linked gallery script for full details.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Tutorial
     - What you get
   * - :doc:`field_ert_data_qc`
     - Load field ERT data, run QC plots, and export inversion-ready files.
   * - :doc:`hydrology_to_ert`
     - Go from hydrologic outputs to ERT forward modeling and inversion.
   * - :doc:`hydrology_to_tdem`
     - Convert hydrology outputs to conductivity and run TDEM/FDEM workflows.
   * - :doc:`joint_inversion`
     - Run structure-constrained and geostatistical joint ERT+SRT inversion.
   * - :doc:`time_lapse_monitoring`
     - Build and invert multi-time ERT monitoring datasets.
   * - :doc:`seismic_structure_constraints`
     - Use seismic structure to constrain resistivity inversions.
   * - :doc:`agent_workflows`
     - Run agent-assisted workflows locally or in the hosted web app.
