Tutorials
=========

These tutorials are end-to-end guides for common workflows. Each tutorial points
to a runnable example in `examples/` and a rendered page in the examples gallery.

.. list-table::
   :header-rows: 1
   :widths: 30 70

   * - Tutorial
     - Description
   * - :doc:`tutorial_field_ert_qc`
     - Field ERT quality control and export for inversion
   * - :doc:`tutorial_hydro_to_ert`
     - Hydrology outputs to ERT forward modeling
   * - :doc:`tutorial_timelapse`
     - Time-lapse inversion with optional structural constraints
   * - :doc:`tutorial_3d_ert_forward`
     - 3D ERT forward modeling with topography-aware meshing
   * - :doc:`tutorial_tdem_workflow`
     - TDEM forward modeling for layered Earth responses
   * - :doc:`tutorial_seismic_structure`
     - Seismic structure extraction and constrained ERT meshes
   * - :doc:`tutorial_mc_uncertainty`
     - Monte Carlo uncertainty for ERT-to-water content conversion
   * - :doc:`tutorial_windowed_timelapse`
     - Windowed time-lapse inversion setup for large monitoring datasets
