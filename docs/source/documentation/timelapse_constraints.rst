Time-Lapse and Constraints
==========================

Time-lapse ERT inversion enables monitoring of subsurface changes. Structural
constraints from SRT or other sources can stabilize inversion and improve
interpretability.

Key Ideas
---------

- Temporal regularization links consecutive time steps.
- Windowed inversion scales to long time series.
- Structural constraints use velocity interfaces or geological priors.
