Geophysics: SRT
===============

Seismic refraction tomography (SRT) is supported for forward modeling and for
structure-constrained ERT inversion.

What You Can Do
---------------

- Create synthetic travel-time data
- Invert for velocity models
- Extract velocity interfaces to constrain ERT meshes
