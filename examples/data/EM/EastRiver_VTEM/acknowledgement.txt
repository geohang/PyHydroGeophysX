East River (Crested Butte, Colorado) 2017 airborne EM demo data
================================================================

------

Survey and system
-----------------
The data were collected October to November 2017 by Geotech Ltd. under contract
to the USGS, using the VTEM ET time-domain helicopter-borne electromagnetic
system: 1,984 line-kilometers over a 483 square-kilometer area of the upper East
River watershed, a heavily studied mountain hydrology and critical-zone site.

Measured quantity: normalized, primary-field-corrected, z-component receiver-coil
response (dB/dt), in volts / (meter^4 * ampere) = V/(m4*A). The response is
recorded in 52 time gates whose center times run from 6.944e-6 s to 8.255e-3 s,
measured relative to the beginning of the transmitter ramp-down. Per-sounding
sensor height above bare earth (ALT) and a NAVD88 ground elevation are provided.

Files in this folder
--------------------
eastriver_vtem_line22030.csv
    Workbench TDEM multi-sounding demo. Column 0 = gate center time (s); each
    following column (snd01..snd22) = one sounding's normalized dB/dt across the
    gates. Built from flight line 22030 in the 200-series processed data: a
    3.0-km height-stable segment (sensor altitude 53-105 m, median 82 m),
    decimated to 22 soundings at about 140 m spacing, keeping the 30 early gates
    (6.944e-6 to 3.912e-4 s) that stay above the noise floor across the segment.

eastriver_vtem_line22030_geometry.csv
    Per-sounding metadata: index, distance along line (m), UTM easting/northing
    (WGS84 zone 13N), and sensor altitude above ground (m). The workbench auto-loads
    this companion file with the data; its easting/northing put the plan-view map on
    real UTM coordinates, and its distances set the section's x-axis.

eastriver_vtem_line22030_usgs_resistivity.csv
    The USGS PUBLISHED inverted resistivity model for the same soundings, as a
    reference "answer." Column 0 = layer depth center (m); each following column
    = that sounding's resistivity (ohm-m) from the 30-layer smooth 1D AarhusInv
    inversion in the data release.

eastriver_workbench_vs_usgs.png
    The workbench stitched 1D inversion of the dB/dt data (top) next to the USGS
    published model (bottom) for line 22030.

eastriver_vtem_area.csv
    A 2D AREA demo (70 soundings) for the plan-view resistivity MAP. The soundings
    are grid-decimated from many 200-series flight lines across the East River
    valley (about 9 x 14 km), so the "Plan slice" view is a real filled map instead
    of a single line of points. Same 30-gate TDEM format (a time column, then one
    column per sounding).

eastriver_vtem_area_geometry.csv
    Geometry for the area demo: index, UTM easting/northing (zone 13N), distance,
    sensor altitude. Auto-loaded with the data file, so the plan-view map uses UTM.

eastriver_area_depthslices.png
    The area demo inverted and shown as plan-view resistivity maps at 13, 52 and
    95 m depth. This is what the "Plan slice" view produces.

Recommended workbench settings (EM module, TDEM)
------------------------------------------------
Load eastriver_vtem_line22030.csv, set the geometry, and press "Run inversion":
  Geometry:   source radius 13 m (the VTEM ET transmitter loop is about 26 m
              across), height 82 m (segment median sensor altitude),
              orientation z, waveform step_off.
  Inversion:  layers 13, min thickness 8 m, max thickness 55 m, smoothness 0.5,
              relative error 0.08, max iterations 10.
  Calibration: set "Reference ρ (Ω·m)" to about 320 for reliable absolute values
              (see the Calibration note below). Leave it 0 to just de-rail the fit
              with the rough Auto-calibrate.
The companion geometry file is loaded automatically, so the section x-axis uses
real distance and the plan-view map uses UTM easting/northing; height is read per
sounding (it barely changes this early-time result). Line 22030 is a single flight
line, so the plan-view "map" is a string of points; use it mainly with "View:
Section".

For the plan-view MAP, load eastriver_vtem_area.csv instead (70 soundings across
the valley). Set Max soundings to 70 or more and press Run; inverting 70 soundings
takes a couple of minutes. Then "View: Plan slice" shows a filled resistivity map
on UTM axes and the Depth slider steps through the layers (see
eastriver_area_depthslices.png). A good geometry for it: height 74 m, otherwise
the settings above.

Calibration and the absolute resistivity
----------------------------------------
The published dB/dt is normalized by the transmitter moment, while the workbench's
1D forward is not, so the two differ by an amplitude factor ("data scale"). Without
it the inversion rails to the resistivity bounds (mean chi-square about 9). But the
absolute resistivity LEVEL and the data scale are mathematically degenerate: any
scale fits the data equally well, with the resistivity sliding to compensate. So
the data alone cannot fix the level, and the automatic "Auto-calibrate" (a rough
amplitude guess from the decay shape) gets the fit into the right ballpark but the
absolute resistivity is unreliable and inconsistent between datasets.

To get reliable, consistent absolute values, set "Reference ρ (Ω·m)" to a
known/expected background resistivity (from a borehole or regional geology). For
this valley about 300-320 ohm-m is a good choice; it yields data scale about 0.25
(which independently matches the constant obtained by forward-modeling the USGS
models through the workbench forward), a mean chi-square below 1, and a near-surface
resistivity consistent with the USGS model and consistent between the line and the
area datasets. In the top ~200 m (the early-time depth of investigation) the
recovered structure follows the USGS model, including the central conductor near
1300-1500 m; deeper cells are blanked as unconstrained. The recovered model is
still blockier and biased somewhat more resistive at depth than the USGS smooth
laterally-constrained inversion — that is the limit of an independent-1D approach,
separate from the calibration. Per-sounding sensor height has almost no effect at
these times, so loading geometry is about the map coordinates, not the fit.

Full dataset
------------
Only one line's subset is included here for a light demo. The complete release
(all flight lines, raw EM/magnetic/radiometric data, the contractor data report
with the exact transmitter waveform and loop geometry, and the full inverted
resistivity/IP models) is at the DOI and ScienceBase links above.
