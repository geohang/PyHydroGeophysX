# Climate Data Integration Workflow

## Visual Workflow

```
┌───────────────────────────────────────────────────────────────────────┐
│                     CLIMATE DATA INTEGRATION                          │
│                      Two-Environment Solution                         │
└───────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────┐
│                        STEP 1: SETUP (ONE-TIME)                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Command:  .\setup_climate_env.bat                                 │
│                                                                     │
│  Creates:  conda environment "climate_fetch"                       │
│            - Python 3.10+                                          │
│            - NumPy 2.x                                             │
│            - PyDaymet 0.19+                                        │
│            - pandas 2.x                                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│                    STEP 2: CONFIGURE REQUEST                        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Edit:  climate_config_example.json                                │
│                                                                     │
│  {                                                                 │
│    "coords": [-105.3, 40.0],          ← YOUR SITE                 │
│    "dates": ["2021-09-01", "2021-11-30"],  ← YOUR DATES           │
│    "output": "data/climate/climate_data.csv",                      │
│    "pet_method": "penman_monteith",                                │
│    ...                                                             │
│  }                                                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│                    STEP 3: FETCH CLIMATE DATA                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Environment:  climate_fetch (NumPy 2.x)                           │
│                                                                     │
│  Command:  .\fetch_climate.bat climate_config_example.json         │
│                                                                     │
│  Process:  → Activate climate_fetch environment                    │
│            → Call PyDaymet API                                     │
│            → Fetch climate variables                               │
│            → Compute PET                                           │
│            → Compute derived features                              │
│            → Save to CSV + JSON                                    │
│            → Deactivate environment                                │
│                                                                     │
│  Output:   ✓ data/climate/climate_data.csv                         │
│            ✓ data/climate/climate_data.json (metadata)             │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
                                ↓
┌─────────────────────────────────────────────────────────────────────┐
│                STEP 4: USE IN PYHYDROGEOPHYX WORKFLOW               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  Environment:  main (NumPy 1.x + PyGIMLi)                          │
│                                                                     │
│  Code:                                                             │
│                                                                     │
│    workflow_config = {                                             │
│        'use_climate': True,                                        │
│        'climate_config': {                                         │
│            'csv_file': 'data/climate/climate_data.csv', ← LOAD    │
│        },                                                          │
│        'ert_timestamps': ['2021-10-08'],                          │
│        ...                                                         │
│    }                                                               │
│                                                                     │
│    results = coordinator.execute_workflow(workflow_config)         │
│                                                                     │
│  Process:  → ClimateDataAgent loads CSV                            │
│            → Aligns with ERT timestamps                            │
│            → Provides climate context                              │
│            → Continues with ERT inversion                          │
│            → Interprets resistivity with climate                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘


═══════════════════════════════════════════════════════════════════════
                          WHY TWO ENVIRONMENTS?
═══════════════════════════════════════════════════════════════════════

Environment 1: climate_fetch              Environment 2: main
├─ NumPy 2.x (required by PyDaymet)      ├─ NumPy 1.x (required by PyGIMLi)
├─ PyDaymet 0.19+                        ├─ PyGIMLi 1.5.4
├─ pandas 2.x                            ├─ pandas 2.x
└─ Purpose: Fetch climate data           └─ Purpose: Geophysical inversion

         ↓ Communicate via CSV files ↓

    Climate data           ──→        ERT inversion
    fetching                          with climate context


═══════════════════════════════════════════════════════════════════════
                             CSV FILE CONTENTS
═══════════════════════════════════════════════════════════════════════

climate_data.csv:
├─ Raw Variables
│  ├─ prcp              (precipitation, mm/day)
│  ├─ tmin, tmax        (temperature, °C)
│  ├─ srad              (solar radiation, W/m²)
│  ├─ vp                (vapor pressure, Pa)
│  ├─ dayl              (day length, seconds)
│  └─ pet               (potential ET, mm/day)
│
├─ Derived Features
│  ├─ prcp_antecedent_1d, 3d, 7d, 14d  (antecedent precip)
│  ├─ p_minus_pet       (moisture balance)
│  ├─ prcp_cumulative   (cumulative precipitation)
│  ├─ temp_range        (daily temperature range)
│  └─ temp_mean         (mean daily temperature)
│
└─ Index: datetime (daily timestamps)

climate_data.json (metadata):
├─ coords              (site coordinates)
├─ dates               (date range)
├─ variables           (fetched variables)
├─ pet_method          (PET calculation method)
├─ shape               (data dimensions)
└─ fetched_at          (timestamp)


═══════════════════════════════════════════════════════════════════════
                          TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════

Problem                              Solution
─────────────────────────────────────────────────────────────────────
conda not found                      Install Anaconda/Miniconda

environment not found                Run .\setup_climate_env.bat

CSV file not found                   Run .\fetch_climate.bat first

ImportError: pydaymet                Activate climate_fetch env first

Wrong NumPy version                  Check you're in correct env
                                     - climate_fetch: NumPy 2.x
                                     - main: NumPy 1.x

PyGIMLi import error                 Don't use PyGIMLi in climate_fetch

ClimateDataAgent error               Provide csv_file in climate_config


═══════════════════════════════════════════════════════════════════════
                            QUICK COMMANDS
═══════════════════════════════════════════════════════════════════════

# Setup (once)
.\setup_climate_env.bat

# Fetch climate data
.\fetch_climate.bat climate_config_example.json

# Or with command line
conda activate climate_fetch
python fetch_climate_data.py --coords -105.3 40.0 --dates 2021-09-01 2021-11-30 --output data/climate/climate_data.csv
conda deactivate

# Check environment
conda activate climate_fetch
python -c "import numpy, pydaymet; print(f'NumPy: {numpy.__version__}, PyDaymet: {pydaymet.__version__}')"
conda deactivate
