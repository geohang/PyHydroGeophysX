Licence texts of code that packages bundle without including the text
themselves: native libraries in a wheel's .libs or .dylibs folder (pyproj,
for one) or in a conda package's Python folder (pgcore), header-only libraries
a conda recipe compiles in (pybind11, Eigen), and conda packages that ship no
licence file (libsqlite). packaging/release_audit.py copies the matching texts
into an archive's LICENSES/<component>/vendored/ folder.

Each file is the upstream text, unchanged, taken from the release named below;
SHA-256 of the file as stored here.
