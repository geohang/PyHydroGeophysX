PyHydroGeophysX#

Connect geophysical data and hydrological modeling. Predict survey responses from hydrological states, interpret observations through petrophysics, and investigate how subsurface conditions change through time. Start with the model–data interaction, then explore the workflows in Python or Desktop Studio.

Examples by task

The loop this package closes#

Information travels in both directions. A hydrological state predicts what a survey should measure, and a survey constrains what the model should hold.

Stage 1 uses Hydro_modular; stage 4 ends in model_input, which writes MODFLOW 6 and ParFlow inputs without touching the source model. How the two connect walks the whole loop.

Your surveys, from data to results#

Work with ERT, seismic, TDEM/FDEM, gravity and magnetics, or connect hydrological outputs through petrophysical relationships. See the desktop guide for supported inputs and project workflows.

Video walkthroughs: Qt Desktop Studio, web agent, manual installation, and ADERT speed comparison.

Choose a workflow#

One card per stage of the loop above. Each opens a tutorial that names the inputs it expects and the result it produces.

1. Predict a survey response

Turn hydrological outputs into resistivity or conductivity through petrophysics, then simulate what a survey would record. The electromagnetic route covers TDEM and FDEM.

Hydrology to ERT
2. Read and check field data

Load a field dataset, inspect it, remove what should not be inverted, and export an inversion-ready file. Supported formats.

Field ERT Data QC
3. Recover a model

Invert one survey or a monitoring series. Structural constraints and joint ERT and seismic inversion combine complementary measurements.

Time-Lapse Monitoring
4. Return the result to the model

Map an interpreted quantity onto the hydrological grid and write MODFLOW 6 or ParFlow inputs for the next run.

Write updates back to hydrological models

Any stage can be driven by an assistant instead of by hand: see AI-assisted workflows.
